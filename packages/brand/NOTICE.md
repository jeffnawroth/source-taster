## Separate scopes in this directory

| Material                                                                                                                                              | Scope                                                                                                           |
| ----------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Generator and test code: `src/`, `scripts/`, `test/`                                                                                                  | AGPL-3.0-or-later, like the rest of the project software.                                                       |
| Two-drop mark artwork: the SVG masters in `masters/` and the PNG/ICO/SVG files in `exports/`, each listed with its SHA-256 in `exports/manifest.json` | Brand artwork, covered by the draft notice below. This includes the full, 16–32 px optical and monochrome cuts. |
| `masters/gamut-mapping.json`                                                                                                                          | Colour-mapping record for the artwork.                                                                          |

The masters and exports contain no font software and no wordmark text. The
project's font licences (the full Atkinson Hyperlegible Next, IBM Plex Mono and
Noto Sans OFL-1.1 notices), Adobe's Apache-2.0 starter notice and the Lucide ISC/
Feather MIT notices keep their own scope and locations. This notice changes
none of them.

Earlier repository copies of the mark (for example the #191/#194/#199
prototypes) may already carry permissions under the repository's AGPL licence.
Whether they do is an open #207 question. This draft does not withdraw or narrow
any existing grant.
