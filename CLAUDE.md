# CLAUDE.md

## Gotchas

```bash
pnpm build:types          # build @source-taster/types — do this before typecheck/dev after touching schemas
pnpm dev                  # types + parallel dev servers (extension, web, docs, landing); API runs but AnyStyle parsing is unavailable
pnpm dev:docker           # same, plus starts the anystyle service in Docker — needed for reference parsing
```

- Every controller parses input with Zod schemas from `@source-taster/types`. `registerOnError()` normalizes all errors to `{ success:false, error, message }`; never return raw/unwrapped data from a controller. Middleware order in `apps/api/src/index.ts` is load-bearing — don't reorder it.
- Manifest is generated by `apps/extension/scripts/prepare.ts`; edit there (not a static `manifest.json`) to change permissions/pages
- Deep dives: `apps/docs/architecture.md`, `data-models.md`, `matching-scoring.md`, `api.md`.
