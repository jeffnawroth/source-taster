# For Reviewers

**AI-generated references are a growing problem in peer review. Studies show that fabricated citations are difficult to spot manually — but The Source Taster catches them automatically.**

## Why Reviewers Need This Tool

- **40% of AI-generated citations are fabricated** — and they look convincing
- **Traditional plagiarism checkers don't detect hallucinated references** — they only check copied text
- **Manual verification is time-consuming** — 62.8% of researchers report struggling with it

The Source Taster gives you a fast, transparent way to verify every reference in a manuscript.

## Batch-Verify an Entire Bibliography

1. Copy the reference list from the manuscript under review
2. Paste it into the extension or upload the PDF
3. The system extracts all references, searches 5 academic databases, and scores each one
4. Review the colour-coded results in seconds

### What the Scores Mean

| Score | Classification | Action |
|---|---|---|
| ≥90% | Exact Match | Verified — exists in academic databases |
| 70–89% | Strong Match | Likely real — minor formatting differences |
| 40–69% | Possible Match | Check manually — author, title, or year mismatch |
| <40% | No Match | Not found — likely hallucinated |

## Transparent Scoring

Every match includes a field-by-field breakdown:

- **Title similarity** — Levenshtein-Damerau fuzzy match
- **Author match** — Normalised name comparison
- **Year match** — Exact or nearby year
- **Journal / venue match**
- **DOI / identifier match**

No black box — you see exactly why each reference scored what it did.

## Privacy & Confidentiality

- The extension is stateless — manuscripts are never stored
- References are only sent to academic databases for verification
- No data is logged or retained

## Recommended Workflow

1. Receive a manuscript for review
2. Copy the bibliography section
3. Run it through The Source Taster
4. Note any "No Match" or low-scoring references in your review
5. Flag systematically fabricated citations to the editor

## Accuracy

Validated in a controlled Master's thesis study at the University of Siegen:
- **93%** exact-match rate on genuine APA references
- **100%** hallucination detection on synthetic fabrications
- **<3 seconds** average processing time per reference
- **10 citation styles** tested

## Integration

The Source Taster works as a Chrome extension (also Edge, Brave, Opera) and Firefox add-on. No account required — just install and use.
