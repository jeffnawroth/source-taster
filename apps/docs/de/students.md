# Für Studierende

**Dein Professor erwartet echte Quellen. KI-generierte Referenzen sehen überzeugend aus — aber bis zu 40 % existieren nicht.** The Source Taster hilft dir, jede Quellenangabe zu prüfen, bevor du deine Arbeit abgibst.

## Kurzanleitung

1. **Extension installieren** — [Chrome Web Store](https://chromewebstore.google.com/detail/the-source-taster/leggmjghcbdfilhfkgnllhnhhbalpanp) (funktioniert auch mit Edge, Brave, Opera)
2. **Seitenleiste öffnen** — Klicke auf das Source-Taster-Symbol in der Browser-Symbolleiste
3. **Referenzen einfügen** — Kopiere ein Literaturverzeichnis oder einzelne Zitate und füge sie ein
4. **Ergebnisse prüfen** — Grün = verifiziert, gelb = unsicher, rot = wahrscheinlich halluziniert

## In deinem Workflow

### Schreiben in Word, Google Docs oder Overleaf

1. Füge Zitate wie gewohnt in dein Dokument ein
2. Markiere das Literaturverzeichnis, Rechtsklick → "Bibliographie prüfen"
3. Die Extension extrahiert jede Referenz, durchsucht 5 akademische Datenbanken und zeigt dir, welche echt sind

### Einzelne verdächtige Referenz prüfen

Eine Quellenangabe gefunden, die komisch wirkt? Füge sie direkt in die Extension ein:

- **Exakte Übereinstimmung (grün)** — Die Referenz existiert in akademischen Datenbanken
- **Mögliche Übereinstimmung (gelb)** — Teilweise Übereinstimmung — prüfe die Abweichungen
- **Keine Übereinstimmung (rot)** — In keiner Datenbank gefunden — wahrscheinlich halluziniert

## Warum das wichtig ist

- **93 %** der echten APA-Referenzen werden korrekt verifiziert
- **100 %** der erfundenen Referenzen werden erkannt
- **Unter 3 Sekunden** pro Referenz — prüfe ein ganzes Literaturverzeichnis in Minuten
- **10 Zitierstile** unterstützt — APA, MLA, Chicago, IEEE, Vancouver, Harvard, ACS, AMA, Oxford, Springer

## Tipps

- **Prüfe verdächtige Zitate immer** — Wenn eine Referenz zu obskur oder zu perfekt wirkt, könnte sie KI-generiert sein
- **Prüfe dein gesamtes Literaturverzeichnis vor der Abgabe** — erkannte Probleme frühzeitig
- **Ergebnisse exportieren** — Kopiere Einzelergebnisse oder den gesamten Bericht für deine Unterlagen

## Datenschutz

Die Extension ist zustandslos — es werden keine Referenzdaten lokal gespeichert. Deine API-Keys werden AES-256-GCM-verschlüsselt.
