# Für Gutachter

**KI-generierte Referenzen sind ein wachsendes Problem im Peer Review. Studien zeigen, dass erfundene Zitationen manuell schwer zu erkennen sind — aber The Source Taster erkennt sie automatisch.**

## Warum Gutachter dieses Tool brauchen

- **40 % der KI-generierten Zitationen sind erfunden** — und sie sehen überzeugend aus
- **Herkömmliche Plagiatsprüfungen erkennen halluzinierte Referenzen nicht** — sie prüfen nur kopierten Text
- **Manuelle Verifikation ist zeitaufwendig** — 62,8 % der Forschenden berichten von Problemen damit

The Source Taster bietet eine schnelle, transparente Möglichkeit, jede Referenz in einem Manuskript zu prüfen.

## Bibliographie im Batch prüfen

1. Kopiere das Literaturverzeichnis aus dem zu prüfenden Manuskript
2. Füge es in die Extension ein oder lade das PDF hoch
3. Das System extrahiert alle Referenzen, durchsucht 5 akademische Datenbanken und bewertet jede
4. Sieh dir die farbcodierten Ergebnisse in Sekunden an

### Was die Bewertungen bedeuten

| Score | Klassifikation | Handlung |
|---|---|---|
| ≥90 % | Exakte Übereinstimmung | Verifiziert — existiert in akademischen Datenbanken |
| 70–89 % | Starke Übereinstimmung | Wahrscheinlich echt — geringe Formatierungsunterschiede |
| 40–69 % | Mögliche Übereinstimmung | Manuell prüfen — Autor, Titel oder Jahr abweichend |
| <40 % | Keine Übereinstimmung | Nicht gefunden — wahrscheinlich halluziniert |

## Transparentes Scoring

Jeder Treffer enthält eine feldbasierte Aufschlüsselung:

- **Titelähnlichkeit** — Levenshtein-Damerau-Fuzzy-Match
- **Autoren-Übereinstimmung** — Normalisierter Namensvergleich
- **Jahres-Übereinstimmung** — Exaktes oder nahes Jahr
- **Journal-/Verlagsübereinstimmung**
- **DOI-/Identifier-Übereinstimmung**

Keine Blackbox — du siehst genau, warum jede Referenz wie bewertet wurde.

## Datenschutz & Vertraulichkeit

- Die Extension ist zustandslos — Manuskripte werden nie gespeichert
- Referenzen werden nur zur Prüfung an akademische Datenbanken gesendet
- Es werden keine Daten protokolliert oder aufbewahrt

## Empfohlener Workflow

1. Manuskript zur Begutachtung erhalten
2. Literaturverzeichnis kopieren
3. Mit The Source Taster prüfen
4. „Keine Übereinstimmung"- oder niedrig bewertete Referenzen im Review vermerken
5. Systematisch erfundene Zitationen der Redaktion melden

## Genauigkeit

Validiert in einer kontrollierten Masterarbeit an der Universität Siegen:
- **93 %** exakte Trefferquote bei echten APA-Referenzen
- **100 %** Erkennung synthetischer Fälschungen
- **<3 Sekunden** durchschnittliche Verarbeitungszeit pro Referenz
- **10 Zitierstile** getestet

## Integration

The Source Taster funktioniert als Chrome-Erweiterung (auch Edge, Brave, Opera) und Firefox-Add-on. Kein Konto erforderlich — einfach installieren und loslegen.
