```sh
node apps/server/ops/backup.mjs export
```

Plaintext is never spooled during export. Private temporary directories contain bounded ciphertext and receipts and are cleaned on completion/failure. Crash-killed temporary directories require the host's private ephemeral-directory cleanup; do not snapshot them.
