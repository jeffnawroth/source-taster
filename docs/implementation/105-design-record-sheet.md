## Behavior

The existing owned PDFKit adapter now renders PDF C: overview, all six labelled
Verdict counts including zero, separately named Status counts, numbered Reference
records, aligned label/content fields and neutral separators. Verdict colour is
confined to redundant vector marks; labels/counts/evidence remain neutral. Links
use the generated accent-text role. `opaque.white` from design-tokens is the
intentional paper-only mapping, including composited borders; no application
appearance, component, font or brand asset enters through tokens.

Atkinson Hyperlegible Next Regular/Bold/Italic and IBM Plex Mono Regular are local
static TTFs. Supported missing graphemes use the existing matching Noto fallback;
impossible text fails the complete job with `unsupported-character`. Every actual
variant and full OFL notice has a pinned SHA-256 in
[`fonts/manifest.json`](../../apps/server/src/reports/fonts/manifest.json), with
immutable upstream URLs, versions and the honest Noto acquisition limitation in
[`fonts/README.md`](../../apps/server/src/reports/fonts/README.md). The production
build's exact font/notice bytes and its emitted worker are exercised by
`report-assets.test.ts`.

The report projects the frozen authorized Check, immutable input, effective and
unchanged system/manual Verdicts, checked fields/revision/result ID, provenance,
and each result's Scoring rules version. Running slots retain current Status and
exclude historical results. Browser drafts and export-only choices never become
checked evidence. No report changes Quota. Existing job/cancel/download/expiry,
Check-deadline, ownership and no-sharing boundaries remain. A new regression also
caught and fixed missing feature-scope revalidation after rendering: the worker
now discards generated bytes when entitlement is lost before publication, under
the current-authority fence and outside the store transaction.

Structure closures preserve heading order, language, Unicode text, multi-page
reading content and Link/annotation associations. Redundant vectors, separators,
wordmark and pagination are Artifacts. Checked-field introductions stay with
their first field. There are no layout tables, so table-header associations do
not apply. The PDF/UA identification remains deliberately unset.
