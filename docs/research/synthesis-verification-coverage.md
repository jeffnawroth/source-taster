## Reading the classifications

- **design recorded**: a concrete mechanism is selected, including an intentionally deferred feature's launch hook or explicit absence of required preparation. It does not mean implemented or accepted.
- **explicit qualification gate**: an accepted design/selection protocol identifies required measured, contractual, host or browser evidence. The actual configuration or capability can remain unknown until that gate; a failed gate cannot silently relax v3.3.
- **genuine design gap**: the sources do not select a necessary mechanism or resolve a concrete interaction. A link to an accepted ADR does not close it.
- **candidate amendment**: a recorded possible requirement change, not an approved exception. Such candidates are collected separately even when a row has another primary classification.

Every row names the controlling mechanism and remaining criterion. All must criteria ultimately need dated/versioned acceptance through **both clients**, with section 14.6 browser coverage ([acceptance][S16], [client protocol][A6-clients], [native release checks][A3-release]). Should deviations are logged and do not block launch; deferred features are excluded except their specified preparation ([obligations][S-obligations]). Missing ID numbers are absent from the specification, not omitted rows: STR-09 and ABG-07/08/09 do not exist.

## Unnumbered constraints and source inventory

1. **Quality targets remain six independent obligations.** §14.4 requires ≥400 real references, ≥5 styles including DIN ISO 690, both languages, ≥20% books/chapters, ≥10% web, plus ≥150 invented/falsified from current AI models. Targets: real correctly cited APA Correct ≥93% AI/≥77% parser; red false alarms ≤1% AI/≤3% parser across real correctly cited references; invented/falsified not Correct ≥98%; entirely invented red ≥95%. [ADR-0006 record classes/floors][A6-classes] add ≥300 real-correct/≥100 APA, ≥30% German real, ≥75 entirely invented, ≥3 models/≥2 providers and ≥20 real records in **each of eleven** styles. These strengthen composition, not reduce target obligations. Eleven-style structuring ≥90%, non-AI 19/20 document segmentation, parser Verdict targets and FA-ERF-02 10-per-format extraction are **separate gates** ([§14.4][S144], [ADR-0006][A6-floors]).
2. **Ground truth and leakage control.** Human identity/field review against canonical entries; expected CSL values stay as written, even erroneous/abbreviated. Private, frozen evaluation repository separate from Development set/documents; only Development calibration; no user-reported copies in any set/fixture. Independently rebuilt public-metadata cases enter Development first ([ADR-0006][A6-ground-truth], [ADR-0010][A10-grounding], [ADR-0022][A22-improvement]). Measure newest slot result and require accepted Source identity for Correct. Outside-coverage cases are additional regression records, not a way to reclassify false alarms or shrink denominators.
3. **Determinism and evidence.** Same input/source situation/settings must give same Verdict; no AI decides it ([§8][S8]). Preserve raw/normalized fields, original input, retrieved/scored Candidates, failure/call/cache observations, search/scoring/configuration versions and provenance as deletable Check content. Six-decimal stored precision, two-decimal display and independent full agreement prevent rounding from creating correctness. All normalizations active; user Strict/rule toggles remain deferred. Canonical weights are fixed launch defaults, not the prototype's tunable demonstrations ([§8.2–8.3][S82], [ADR-0008][A8-fields], [ADR-0007 log][A7-retraction]).
4. **Styles are selected.** Server citeproc-js behind a typed facade, pinned CSL/locale assets shipped locally, AGPL renderer outside transport layer, CC BY-SA asset notices. Manifest: APA 7/en-US, MLA 9/en-US, Chicago author-date 18/en-US, IEEE/en-US, Vancouver NLM sequence/en-US, Harvard Cite Them Right/en-GB, ACS/en-US, AMA 11/en-US, Oxford bibliography/en-GB, Springer basic author-date/en-US, DIN ISO 690:2013-10 author-date/de-DE. Parser additionally recognizes Chicago notes-bibliography. One-entry suggestions omit number labels/disambiguation suffixes; locale never follows interface toggle. Production pins/rendering/license evidence is pending, not a missing style-family decision ([ADR-0011 manifest][A11-styles]).
5. **Coverage precedes DOI.** The fixed 45-type CSL table places article/report/thesis/review/dataset/software/document types on article route; book/chapter/entries/classic/pamphlet on book; webpage/post-weblog/post on web; 22 legal/archival/standard/patent/media and communication types outside coverage. Unknown/missing non-CSL type alone defaults article. Outside coverage gets Not verifiable before DOI, even if supplied; no deception proof, plagiarism, automatic document change, style-conformity judgment or launch statement-support assessment ([§17][S17], [ADR-0011 mapping][A11-routes], [ADR-0008 precedence][A8-verdict]). Do not mistake the deferred specialist DataCite source for absence of all responsible article-route sources for a `dataset`.
6. **Privacy, browser and host constraints apply to these flows.** Text-only grounded extraction; no AI files/images/tools; responsible Data source disclosures only; source-origin identifier cache permitted only by terms, initial 24 h/no negatives/no user query cache. Check logs/Candidates share content expiry, operational telemetry stays content-free. Untrusted URLs use HTTP/HTTPS, five redirects, 5 MiB wire/decompressed limits plus validated actual destinations; safety refusal is incomplete evidence. Untrusted document extraction needs OS-enforced isolation without DB/keys/unrestricted network, not just a Node child process. Mandatory file/count/time targets cannot be silently reduced for host capacity. Browser contract: extension Chrome/Edge/Brave/Opera/Firefox latest two and current ESR; web Chrome/Edge/Firefox/Safari latest two. Accepted desktop/Windows 11/current macOS and Brave feature-line readings do not replace native evidence ([§14.6][S146], [ADR-0002 platforms][A2-platforms], [ADR-0015][A15-parser]).

7. **Structuring has separate operating time targets.** It precedes the accepted verification clock. AI chunks break on paragraphs or detected reference boundaries, overlap slightly and deduplicate by original span; parallel execution, flat schema validation and schema warm-up are selected. AI operating targets are 100 references ≤30 s at p95 and 1,000 ≤3 min; if quality passes but no candidate meets time, the fastest passing candidate is selected and the Operator adjusts that operating Initial value. Non-AI document operating targets are 100 references ≤10 s at p95 and 20 MB/1,000 references ≤60 s at p95. These are ADR settings, **not substitutes or relaxations for FA-UEB-40–43**, and neither exact chunk sizes/concurrency nor measured timing has been qualified ([ADR-0010 configuration/time][A10-config], [ADR-0011 limits][A11-limits]).

## Actual unresolved choices versus qualification gates

**G1 — comparison details remain unselected, not measured failures.** ADR-0008 expressly rejects treating prototype edit-distance, name/date weights, order penalty, total/strong-field/margin/mixed/counterevidence numbers as production choices. The accepted identity/precedence/page formula/precision are concrete; the exact string metric and normalization edge behavior, one-to-one name similarity parameters, nonnumeric page handling and arithmetic rounding policy still need a versioned definition. Numeric choices are delegated to Development-only calibration and the fixed quality gate; that protocol is accepted, but it does not supply the choices. This is a bounded algorithm/configuration gap, not a reason to reopen all Verdict policy or a claim that only running tests remains ([ADR-0008 evidence/fields/calibration][A8-fields]).

**G2 — identifier evidence versus Candidate allocation needs a deterministic interaction rule.** ADR-0007 and ADR-0008 both require a five-Candidate ceiling **including identifier evidence**, while retaining the initial 1 combined + 2 title + 2 authors/year allocation. They do not say precisely which bibliographic bucket loses capacity when distinct identifier-derived Candidates already consume it, how duplicate slots refill, or how that ordering preserves sufficient mixed/identity counterevidence. A harmless resolved identifier can terminate early, but confirmed conflict/ambiguous identifier cases continue, making the interaction observable. No six-plus-Candidate interpretation is allowed. The allocation policy must be explicit, then measured/versioned; it is not closed merely by a cap statement ([ADR-0007 candidates][A7-candidates], [ADR-0008 handoff][A8-calibration]).

**G3 — protected selection coverage is unresolved wording/product scope.** Native menu/panel APIs and packaging are selected; OS/ESR/Brave interpretations, leases and content retention are addressed elsewhere. However the linked selection investigation leaves protected pages, built-in PDF viewers, local files, canvas editors and frames unresolved against FA-ERF-03's “any web page”. Native browser execution is a qualification gate; deciding an exception or fallback that narrows that obligation is a separate client decision/amendment candidate. A popup remains deferred and cannot silently substitute ([selection conclusion][selection], [ADR-0002 platforms][A2-platforms]).

**G4 — source and host capacity is an explicit feasibility gate with possible design consequences.** Sequential routes, source order, ten active References/Check, shared PostgreSQL limiter, retry/deadline policy and live protocol are already selected. Sustainable allowances, Google Books quota/budget, mixed-workload/cache distribution, exact capacity thresholds and the security-qualified host layout are not. At 50 ×100/180, completion needs approximately **27.78 References/s**; ADR-0007's conditional Crossref no-cache lower bounds are **2,000 s for 5,000 one-query lookups**, **6,000 s for three queries each**, at 2.5 searches/s. These are arithmetic pressure signals, not measured universal infeasibility. Producing fast grey deadline results does not prove coverage/quality. The accepted response to failed live evidence is revise capacity/routing, gate again, or return any target relaxation to the client. No higher allowance, replacement catalog, unlimited cache, provider switch or weakened isolation is selected in advance ([ADR-0007 budgets/performance][A7-performance], [ADR-0012 stages][A12-stages], [ADR-0015 boundary][A15-parser]).

**G5 — owned parser choice is settled; detailed rules and feasibility are not.** A deterministic handwritten TypeScript module, no learned method/generator/external runtime, identifiers-first conservative parsing, eleven styles, selected extraction/import/rendering ports, as-written fields and development/evaluation separation are accepted. Detailed bibliography boundary/splitting/field heuristics still have to be authored and calibrated; no production algorithm is present in these concept sources. The 19/20 and parser-target gates plus named escalation are explicit. It would be inaccurate either to call the parser approach “not chosen” or to call its acceptance achieved. A failure can reopen target/method choice only through the recorded decision path ([ADR-0011 feasibility/module][A11-feasibility]).

**G6 — AI launch configuration is deliberately unknown under a selected selection rule.** EU open-weight first, then EU Bedrock Haiku, then Sonnet; strongest eligible open-weight contender chosen on Development, first passing exact configuration wins after three AI runs/time gate. Dated provider/model/region/prompt/schema/sampling/chunk-size and cross-provider reserve remain to be selected from evidence. Grounding, chunk fallback, no automatic provider failover and reserve activation are settled. This is not an unowned architecture decision; if nothing passes quality, FA-STR-02 must returns to the client rather than launching parser-only as compliant. Contract versus enforced configuration remains C1 below ([ADR-0010 selection][A10-selection] and [configuration][A10-config]).

**G7 — style and journal-abbreviation gaps are closed at design level.** The style manifest/locale choices and citeproc-js route are selected. ADR-0018 completes the old ADR-0010/0011 abbreviation handoff through attested-match/different/not-determinable rules; unknown evidence is unscored and renormalized, never fabricated identity or silent agreement. Snapshot selection/pins, actual rendered output, source-field reliability, licenses and quality/performance remain qualification evidence. Historical ADR-0002/0016 statements that a PDF report engine is unchosen are likewise superseded by ADR-0017's selected adapter; they are not active verification-design gaps ([ADR-0011 manifest][A11-styles], [ADR-0018][A18-outcomes], [ADR-0017][A17-engine]).

## Synthesis result

All **58 assigned IDs** are mapped. Most behavioral policy is recorded, including lifecycle/billing, source routes, coverage-first deterministic Verdicts, grounding, parser/library/style strategy, independent quality evaluation and live performance protocol. Concrete algorithm/configuration choices remain under G1/G2; restricted-surface selection needs G3 resolution. G4/G5/G6 are explicit feasibility/selection gates with possible later design consequences, not passed tests. Journal abbreviation and style selection are resolved, and pending contractual/browser/host evidence must not be mistaken for design completion or silent v3.3 waivers. C1–C6 preserve the relevant amendment/decision candidates without creating implementation issues.
