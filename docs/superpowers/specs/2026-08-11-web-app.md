# Spec: Web Workspace (Web-Version von Source Taster)

> Status: Entscheidung getroffen — Implementierung gestartet (2026-08-11)
> Entscheidungsmodus: autonom durch Session-Leitung (User hat volle Autonomie übertragen)

## Entscheidung

**Ja — zusätzlich zur Browser-Extension bauen wir eine Web-Version ("Web Workspace")**
unter `sourcetaster.com/app` (SPA). Der komplette Kern-Workflow
(Paste/PDF → Extract → Search → Match → Export) läuft ohne Extension-Installation
im Browser auf `sourcetaster.com`.

## Begründung

1. **Onboarding-Barriere**: Extension-Installation + Berechtigungs-Prompt
   ("liest alle Websites") ist die größte Hürde für Studierende. Ein Link
   "Referenzen prüfen" auf der Landing konvertiert sofort ohne Installation.
2. **Try-before-install**: Nutzer testen das Tool erst, bevor sie host_permissions
   gewähren. Web-Version = Vertrauensanker + Demo für Product Hunt / HN.
3. **Firefox-Engpass umgehbar**: AMO-Listing fehlt noch (nur Chrome Store +
   GitHub-XPI). Firefox-/Safari-/Mobile-Nutzer können sofort arbeiten.
4. **API ist bereit**: Alle Endpunkte (`/api/extract`, `/api/search`, `/api/match`,
   `/api/user/ai-secrets`) sind HTTP-basiert und browserunabhängig. CORS erlaubt
   bereits `X-Client-Id` für Browser-Clients.
5. **Marketing/SEO**: Ein funktionierendes Tool auf der eigenen Domain ist
   Funnel-Ende, Demo-Material und Fundament für den Cloud-Tier (Roadmap Phase 4,
   €9/mo, Account-System, Rate-Limits).
6. **Roadmap-Kompatibilität**: Phase 1.3 (Landing-Erweiterungen) und Phase 4
   (Cloud-Tier) werden direkt unterstützt; die Web-App ist die UI des Cloud-Tiers.

## Kern-Workflow (MVP)

```
Text einfügen ODER PDF hochladen (unpdf, wie Extension)
  → POST /api/extract { text, aiSettings? }          (Anystyle; optional LLM-Key)
  → Referenzen-Liste (CSL-JSON, editierbar entfernen)
  → Pro Referenz: POST /api/search (Batch) → POST /api/match
  → Ergebnisliste: Score-Badge, Feld-Details, "Kein Treffer" = Halluzinations-Verdacht
  → Export: JSON (CSL) + BibTeX-Download
```

## Technischer Stack

- **App**: neue Vue-3-SPA `apps/web` (Vite + TypeScript + Vuetify 3 + Pinia + vue-i18n)
- **Verträge**: `@source-taster/types` (Zod-Schemas; single source of truth)
- **PDF**: `unpdf` (identisch zu Extension `utils/pdfUtils.ts`)
- **Tests**: Vitest (Utils, Stores, ApiClient; keine Browser-Komponententests im MVP)
- **Brand**: Farben aus ROADMAP.md (Primary `#4e2e92`, Secondary `#1f6b7c`,
  Accent `#c9952e`, Success `#2d7a31`), Vuetify-Theme light/dark wie Extension

## Wichtige Verträge (aus packages/types, unverändert konsumieren)

- `POST /api/extract` — `ApiExtractRequest { text, extractionSettings?, aiSettings? }`
  → `ApiExtractData { references: [{ id, originalText, metadata: CSLItem }] }`
- `POST /api/search` — `ApiSearchRequest { references: [{ id, metadata }] }`
  → `ApiSearchData { results: [{ referenceId, candidates: [{ id, source, metadata, url? }] }] }`
- `POST /api/match` — `ApiMatchRequest { reference, candidates, matchingSettings? }`
  → `ApiMatchData { evaluations: [{ candidateId, matchDetails: { fieldDetails, overallScore } }] }`
- `GET/POST/DELETE /api/user/ai-secrets` — `ApiUserAISecretsRequest { provider, apiKey }`
- Alle geschützten Endpunkte: Header `X-Client-Id: <UUIDv4>` (401 wenn fehlt/ungültig)

## Verification-Logik (wie Extension stores/verification.ts)

- Pro Referenz: `search` (Batch über alle Referenzen möglich, Ergebnis je referenceId)
- `match` je Referenz mit ihren Kandidaten; `bestScore = max(overallScore)`
- Klassifikation: bestScore ≥ 85 → "Verifiziert", 50–84 → "Partiell/Überprüfen",
  < 50 oder keine Kandidaten → "Nicht gefunden" (Halluzinations-Verdacht, auffällig)

## Deploy

- `apps/web/Dockerfile`: `node:22-alpine` Multi-Stage → `nginx:alpine`, Port 80
- `docker-compose.yml`: Service `web` auf Port **8084** (Statik, healthcheck curl)
- `release.yml` deploy-Loop: `landing docs api` → `landing docs api web`
- Server-Routing: Caddy auf dem Server — Route `sourcetaster.com/app/*` → `web:8084`
  (SPA nutzt Hash-History → kein Rewrite nötig, keine neue DNS-Domain nötig)
- devproxy: `pnpm dev:kill` Port 5173 (Vite default) passt bereits
