# OpenCode AI-OS Adapter

This adapter explains how the current OpenCode deployment implements the
runtime-neutral AI-OS CORE. The normative rules are in `../../core/`; this
directory does not redefine them.

OpenCode 1.18.18 is the current execution runtime. Its effective permission
state is evidenced by the resolved runtime configuration, not by this prose.
Some controls are technically enforced; worktree use, human review, and the
approved-domain policy also contain instruction-level/process elements. See
`implementation.md` for the distinction.
