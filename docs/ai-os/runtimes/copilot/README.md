# GitHub Copilot AI-OS Adapter

This adapter applies the AI-OS CORE to GitHub Copilot contexts in this
repository. The normative rules are in `../../core/`; this adapter records the
repository's evidenced capability level rather than claiming parity with another
runtime.

The checked-in Copilot integration consists of project instructions. It does
not provide configured per-role permissions, recursion caps, isolated workspaces,
tool boundaries, or approval gates equivalent to the current OpenCode setup.
